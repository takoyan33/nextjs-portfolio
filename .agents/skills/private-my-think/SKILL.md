# private-my-think

## When to Use
- 転職や副業を検討する際に、自分の強みや価値観を整理したいとき

## Instructions

### Step1: 回答作成

- my-think `転職や副業を検討する際に、自分の強みや価値観を整理したいとき`があれば、タイトルを優先して作成する

1. 面接や事前アンケートでの質問回答などの場合
- `assets/ARCHIVE.md` の回答内容や記載方法、文体を参考にする
- 回答を作成してください

2. 志望動機作成の場合
- 志望動機を作成したい場合は、企業名と企業情報と募集要項を`assets/company.md`に追加してください
- それを元に、`assets/ARCHIVE.md` の自分考えを参考にし、志望動機を作成してください
  - `assets/ARCHIVE.md` の回答内容や記載方法、文体を参考にする

## Notes
- 不明点があればユーザーに質問する
